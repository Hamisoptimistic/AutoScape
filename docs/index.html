01 / Architecture

No background daemon.
Just Windows Task Scheduler.

A wallpaper switcher has no business idling in your system tray all day. AutoScape configures a standard user-level scheduled task and hands the job over to Windows.

STEP 01 — ASSIGN

Pick your feeds

Choose Bing 4K, Windows Spotlight, Wallhaven Nature, or Pexels. Assign them independently to your Desktop and Lock Screen.

STEP 02 — SCHEDULE

Choose a cadence

Turn Auto on and pick On Login, Hourly, Every 6 Hours, or Daily at midnight. AutoScape registers one clean user task automatically.

STEP 03 — EXIT

Close the window

Quit AutoScape completely. When the clock hits your interval, Windows runs a silent ~1-second update and exits immediately.

0 MB App closed → Task Scheduler Fires on schedule → ~1 sec Fetch & apply image → 0 MB Process exits
02 / What's included

Built for people who check Task Manager.

Plain local config files, full-resolution exports, and native WPF rendering—without accounts, subscriptions, or Electron bloat.

True 0 MB idle footprint

Nothing lingers in RAM after you close the app. Your memory stays free for browsers, games, or builds.

Four 4K wallpaper feeds

Switch freely between Bing Daily, Windows Spotlight archives, keyless Wallhaven SFW Nature, and curated Pexels landscapes.

Independent Desktop & Lock Screen

Send Wallhaven to your Desktop and Bing to your Lock Screen, with native Fill, Fit, Stretch, Center, or multi-monitor Span.

Local JSON, zero telemetry

Preferences and optional API keys live in a plain JSON file on disk. No login wall, no analytics, no background phone-home.

Uncompressed 4K downloads

Save any wallpaper you want to keep directly to your chosen folder at full resolution with photographer and copyright details preserved.

Native Windows UI

Built on WPF for Windows 10 and 11 (64-bit). Launches immediately and installs under %LOCALAPPDATA% without UAC prompts.
